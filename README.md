
# PetFeed - Үй жануарларын күту журналы

## Жобаның мақсаты
PetFeed - Java тілінде жасалған консольдік бағдарлама.
Ол жануарлардың тамақтануы мен серуендеу уақытын тіркеуге, күтім тарихын бақылауға 
және статистикалық мәліметтерді есептеуге мүмкіндік береді.
Бағдарлама жануарлардың күнделікті күтімін жүйелі ұйымдастыруға көмектеседі.

## Қолданылған технологиялар
- Java
- IntelliJ IDEA
- Git және GitHub
- Scanner

## Жобаның мүмкіндіктері
- Жаңа жазба қосу
- Барлық жазбаларды көрсету
- Жем мөлшерінің статистикасын есептеу
- Белсенді жазбаларды анықтау
- Жануар бойынша жазбаларды іздеу
- Жануардың орташа жем мөлшерін есептеу
- Жалпы серуен уақытын есептеу

## 33-нұсқаның тапсырмалары
1. isActive() әдісіндегі шекті 45 минутқа өзгерту.
2. getTotalWalk() әдісін іске асыру.
3. getAverageByPet(String pet) әдісін іске асыру.

## Жобаны іске қосу
1. Жобаны IntelliJ IDEA арқылы ашу.
2. src/PetFeedApp.java файлын ашу.
3. main() әдісін іске қосу.
4. Консольдегі мәзірден қажетті әрекетті таңдау.

## Жобаның құрылымы
- PetFeed.java - жануарды күту жазбасының класы.
- PetFeedLog.java - жазбаларды сақтау және есептеу.
- PetFeedApp.java - бағдарламаның мәзірі.
- PetFeedTestDrive.java - тесттер.
